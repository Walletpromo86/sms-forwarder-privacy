Esta Política de Privacidade descreve como a aplicação SMS Forwarder ("a Aplicação"), desenvolvida por GOLDSHADOW ("nós", "o Developer"), acede, utiliza e trata os dados do utilizador. Ao instalar e utilizar a Aplicação, o utilizador concorda com os termos descritos nesta política.

Resumo: A Aplicação processa todos os dados localmente no dispositivo. Não existem servidores próprios do developer, não há recolha de analytics, não há tracking, nem publicidade. Os dados só são enviados para os destinos que o próprio utilizador configurar (ex: Telegram, Email ou Webhook).

1. Que dados a Aplicação acede

Para funcionar, a Aplicação solicita as seguintes permissões sensíveis do Android:

PermissãoFinalidade
READ_SMSLer o conteúdo de mensagens SMS recebidas para permitir o seu reencaminhamento.
RECEIVE_SMSDetetar em tempo real a chegada de novas mensagens SMS.
SEND_SMSPermitir o envio de SMS quando essa funcionalidade é usada pelo utilizador (ex: respostas automáticas).
READ_CALL_LOGAceder ao registo de chamadas para permitir o reencaminhamento de notificações de chamadas, caso ativado pelo utilizador.
READ_PHONE_STATEIdentificar o estado do telefone e o número/linha SIM associada, necessário para o correto processamento de SMS em dispositivos com múltiplos SIMs.
NOTIFICATION_LISTENERLer notificações de outras aplicações (se o utilizador ativar esta função) para as poder reencaminhar.
READ_CONTACTSAssociar nomes de contactos aos números de telefone nas mensagens reencaminhadas, tornando a informação mais legível.

2. Como os dados são utilizados

  • Os dados acedidos (SMS, chamadas, notificações, contactos) são processados exclusivamente no dispositivo do utilizador.
  • A Aplicação usa esses dados apenas para construir a mensagem/notificação que será reencaminhada para o destino escolhido pelo utilizador.
  • Nenhum dado é enviado, copiado ou processado em servidores geridos pelo Developer. O GOLDSHADOW não tem acesso a qualquer SMS, chamada, notificação ou contacto do utilizador.

3. Partilha de dados

A Aplicação não partilha dados com o Developer nem com terceiros por sua iniciativa. Os dados só são enviados para os destinos que o próprio utilizador configura explicitamente dentro da Aplicação, nomeadamente:

Telegram (via Bot API) Email (SMTP configurado pelo utilizador) Webhook (URL definida pelo utilizador)

Nestes casos, a comunicação é feita diretamente entre o dispositivo do utilizador e o serviço de destino que ele configurou, usando as credenciais/URLs que o próprio utilizador introduziu. O Developer não intervém nem regista essas comunicações. O utilizador é responsável por garantir que os destinos escolhidos (ex: conta de Telegram, servidor de email, endpoint de webhook) cumprem os requisitos de segurança e privacidade que considerar adequados.

4. Armazenamento de dados

  • Todos os dados de configuração e histórico de mensagens reencaminhadas são guardados numa base de dados local (Room Database), armazenada apenas no armazenamento interno do dispositivo do utilizador.
  • Estes dados não saem do dispositivo, exceto para os destinos de reencaminhamento configurados pelo próprio utilizador.
  • Ao desinstalar a Aplicação, todos os dados armazenados localmente são removidos permanentemente.

5. Analytics, Tracking e Publicidade

  • A Aplicação não integra qualquer SDK de analytics (ex: Google Analytics, Firebase Analytics).
  • A Aplicação não faz tracking de utilizador entre aplicações ou websites.
  • A Aplicação não apresenta anúncios (por agora).
  • Não é feita qualquer recolha de identificadores publicitários (ex: Google Advertising ID) para fins de perfilagem.

6. Segurança

Uma vez que todo o processamento é local, o principal risco de segurança está associado ao dispositivo do utilizador e aos serviços de destino que este configura. Recomendamos que o utilizador:

  • Proteja o dispositivo com PIN/biometria;
  • Utilize apenas destinos de reencaminhamento (Bot Tokens, credenciais de email, URLs de webhook) de fontes fiáveis;
  • Mantenha a Aplicação atualizada.

7. Direitos do Utilizador

Como todos os dados são processados e armazenados localmente, o utilizador tem controlo total sobre eles:

  • Acesso: pode consultar em qualquer momento o histórico guardado na Aplicação.
  • Eliminação: pode apagar o histórico dentro da Aplicação ou desinstalar a Aplicação para remover todos os dados.
  • Revogação de permissões: pode revogar qualquer permissão a qualquer momento através das definições do Android, podendo isso limitar o funcionamento da Aplicação.
  • Portabilidade: não existe um servidor central onde os dados fiquem retidos — os dados residem apenas no dispositivo do utilizador.

8. Crianças

A Aplicação não é direcionada a crianças menores de 13 anos e não recolhe intencionalmente dados de crianças.

9. Alterações a esta Política

Esta Política de Privacidade pode ser atualizada periodicamente para refletir alterações na Aplicação ou por requisitos legais. A data da última atualização está indicada no topo desta página. Alterações significativas serão comunicadas através da página da Aplicação na Google Play Store.

This Privacy Policy describes how the SMS Forwarder app ("the App"), developed by GOLDSHADOW ("we", "the Developer"), accesses, uses, and handles user data. By installing and using the App, you agree to the terms described in this policy.

Summary: The App processes all data locally on the device. There are no Developer-owned servers, no analytics collection, no tracking, and no advertising. Data is only sent to the destinations that the user configures (e.g. Telegram, Email, or Webhook).

1. What data the App accesses

To function, the App requests the following sensitive Android permissions:

PermissionPurpose
READ_SMSRead the content of incoming SMS messages so they can be forwarded.
RECEIVE_SMSDetect new incoming SMS messages in real time.
SEND_SMSAllow sending SMS when this feature is used by the user (e.g. automatic replies).
READ_CALL_LOGAccess call log to allow forwarding of call notifications, if enabled by the user.
READ_PHONE_STATEIdentify phone state and the associated SIM/line, required for correct SMS handling on multi-SIM devices.
NOTIFICATION_LISTENERRead notifications from other apps (if enabled by the user) so they can be forwarded.
READ_CONTACTSMatch contact names to phone numbers in forwarded messages, making the information more readable.

2. How data is used

  • Accessed data (SMS, calls, notifications, contacts) is processed exclusively on the user's device.
  • The App uses this data only to build the message/notification that will be forwarded to the destination chosen by the user.
  • No data is sent, copied, or processed on servers operated by the Developer. GOLDSHADOW does not have access to any user SMS, call, notification, or contact data.

3. Data sharing

The App does not share data with the Developer or with third parties on its own initiative. Data is only sent to the destinations the user explicitly configures within the App, namely:

Telegram (via Bot API) Email (SMTP configured by the user) Webhook (URL defined by the user)

In these cases, communication happens directly between the user's device and the destination service they configured, using the credentials/URLs the user entered themselves. The Developer does not intervene in or log these communications. The user is responsible for ensuring that the chosen destinations (e.g. Telegram account, email server, webhook endpoint) meet the security and privacy requirements they consider appropriate.

4. Data storage

  • All configuration data and forwarded-message history are stored in a local database (Room Database), kept only in the user's device internal storage.
  • This data does not leave the device, except to the forwarding destinations configured by the user.
  • Uninstalling the App permanently removes all locally stored data.

5. Analytics, Tracking and Advertising

  • The App does not integrate any analytics SDK (e.g. Google Analytics, Firebase Analytics).
  • The App does not track users across other apps or websites.
  • The App does not display ads (for now).
  • No advertising identifiers (e.g. Google Advertising ID) are collected for profiling purposes.

6. Security

Since all processing is local, the main security considerations relate to the user's device and the destination services they configure. We recommend that users:

  • Protect their device with a PIN/biometrics;
  • Only use forwarding destinations (bot tokens, email credentials, webhook URLs) from trusted sources;
  • Keep the App updated.

7. User Rights

Since all data is processed and stored locally, the user has full control over it:

  • Access: the user can view the stored history within the App at any time.
  • Deletion: the user can clear the history inside the App or uninstall the App to remove all data.
  • Permission revocation: the user can revoke any permission at any time via Android settings, which may limit the App's functionality.
  • Portability: there is no central server retaining data — data resides only on the user's device.

8. Children

The App is not directed at children under 13 and does not intentionally collect data from children.
